기본 기능(PDF 보기, 노트 생성/삭제, 스크롤)이 완벽히 동작하는 걸 확인한 후에만 새 기능 추가.

**Why:** 유저가 PDF 2페이지 안 보이는 버그를 여러 번 지적했는데 새 기능만 계속 추가해서 매우 화남. "이 기초적인거부터 왜안되냐고"
**How to apply:**
1. 코드 수정 후 반드시 앱 실행 + 실제 동작 확인 (analyze만으로 부족)
2. PDF 렌더링, 노트 CRUD, 스크롤 등 기본 기능 깨지면 즉시 수정
3. 새 기능 추가 전에 기존 기능 회귀 테스트
4. 모든 provider에 로그 추가해서 에러 추적 가능하게
