# 노트 UI 긴급용 기획안 (2026-03-16)

기획안 위치: `docs/260316/노트 UI 긴급용_1~20.png`
브랜치: DK-A

## 1. 화면 구성 (슬라이드 1~6)

### 3패널 레이아웃
- **좌측**: ScrapNote 페이지 썸네일 사이드바 (Page 1, 2, 3... + 각 페이지의 스크랩 썸네일)
- **중앙**: PDF 뷰어 (상단에 열린 PDF 탭 바)
- **우측**: ScrapNote 에디터 (스크랩 카드들이 세로 배치)
- **상단 바**: `< 제목` + 도구 아이콘 (펜, 지우개, 색상, 선 등) + 메뉴(⋮)

### PDF 탭 바
- 여러 PDF를 탭으로 열기 (슬라이드 2)
- 탭 바에서 PDF 전환
- PDF ↔ ScrapNote 위치 전환 가능

### 메뉴 (⋮) 옵션 (슬라이드 3)
- 위치전환
- 스크랩노트관리
- 페이지설정
- 설정

### PDF 열기 (슬라이드 4)
- 지구본/링크 아이콘 클릭 → 팝업으로 PDF 선택
- 팝업은 "모든 노트" 리스트 (Home의 노트 목록 재활용)

### PDF 바 닫기 (슬라이드 5)
- PDF 탭 바 닫으면 → PDF 뷰어 비례 확대

### ScrapNote 접기 (슬라이드 6)
- ScrapNote 닫기/접기 아이콘 → PDF 두 창 보기 (PDF만 전체)
- ScrapNote는 백그라운드에서 진행
- 아이콘 변경 예정

## 2. 스크랩 플로우 (슬라이드 7~9)

### 캡처 플로우 (슬라이드 7)
1. 캡처 도구 선택
2. 캡처 구역 드래그
3. **스크랩 보드 팝업** 표시
4. 스크랩 내용 작성
5. 확인 버튼으로 스크랩 완료

### 하이라이트 플로우 (슬라이드 8~9)
1. 형광펜 도구 선택
2. 텍스트 하이라이트
3. 하이라이트 액션 끝나면 체크 아이콘으로 완료
4. 좌측에 "연결 스크랩 리스트" 표시
5. 하이라이트 영역 텍스트 추출
6. 스크랩 보드 팝업 → 이후 캡처와 동일

## 3. 빠른 스크랩 (슬라이드 10~12)

### 빠른 캡처 (슬라이드 10)
- 캡처 도구 선택된 상태에서 **터치만 하면** 즉시 스크랩
- 하이라이트 도구도 동일

### 아이콘 변경 (슬라이드 11)
- 캡처/하이라이트 활성 시 아이콘 변경
- 추후 아이콘 디자인 변경 예정

### 빠른 스크랩 플로우 (슬라이드 12)
1. 캡처 (터치)
2. 스크랩 보드 없이 바로 스크랩 생성
3. 레이아웃에 동기화
- 하이라이트도 스크랩도 동일 플로우

## 4. 스크랩 수정 (슬라이드 13~20)

### 레이아웃 전환 (슬라이드 13)
- **PDF 선택 시**: PDF 중심 레이아웃 (PDF 크게, ScrapNote 작게)
- **ScrapNote 선택 시**: ScrapNote 중심 레이아웃 (스크랩 카드들 보임)

### 스크랩 선택/수정 (슬라이드 14)
- 길게 터치 → 스크랩 수정 활성화 (이동, 크기 변경, 회전, 삭제)
- 좌측 사이드바에서 선택된 스크랩 틴트 표시

### 복수 선택 (슬라이드 15)
- 다른 스크랩 터치로 복수 선택
- 복수 선택 시 그룹화 활성화

### ScrapNote 페이지 관리 (슬라이드 16)
- 드롭다운: 페이지 선택, 스크랩 개수 표시, 이름 변경
- ScrapNote에 직접 스크랩 작성 가능

### 드래그/드롭 그룹화 (슬라이드 17)
- 좌측 레이아웃에서 드래그/드롭으로 그룹화 가능

### 그룹 표시 (슬라이드 18)
- 그룹화 시 아이콘 변경 및 합병 표시

### 그룹 수정 (슬라이드 19)
- 그룹화된 스크랩은 하나의 스크랩 보드에 같이 표시

### 페이지 이동 (슬라이드 20)
- 스크랩 드래그/드롭으로 페이지 이동 가능
- 이동한 스크랩은 대상 페이지 최상단 위치

## 핵심 변경사항 vs 기존 구현

| 항목 | 기존 | 신규 |
|------|------|------|
| 스크랩 생성 | 마커 생성 → Element 자동 생성 | 캡처/하이라이트 → 스크랩 보드 팝업 → 확인 |
| 빠른 스크랩 | 없음 | 터치만으로 즉시 스크랩 (보드 스킵) |
| ScrapNote 레이아웃 | 우측 고정 | PDF↔ScrapNote 위치 전환, 접기/펼치기 |
| 스크랩 수정 | 없음 | 길게 터치 → 이동/크기/회전/삭제 |
| 복수 선택/그룹화 | 없음 | 복수 선택 → 그룹화 → 합병 표시 |
| 페이지 관리 | 없음 | 드래그/드롭 페이지 이동, 페이지별 관리 |
| PDF 열기 | 기존 방식 | 팝업으로 노트 목록에서 PDF 선택 |

**Why:** 긴급 UI 리워크 - ScrapNote 워크플로우를 실사용 가능 수준으로 개선
**How to apply:** Workspace 화면 전체 레이아웃 재구성 필요. 스크랩 CRUD, 그룹화, 페이지 관리 신규 구현.
